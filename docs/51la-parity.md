# 51.LA 功能对照与验收记录

目标：逐个菜单达到 51.LA 的功能覆盖，并增加有用的新能力。当前状态是开发中，不能把已有相近菜单视为验收通过。

## 参照与验收方法

2026-09-14 使用 Edge 打开用户指定的 `v6.51.la/report/daily`，展开全部菜单，并逐页查看下表页面。仅记录功能与字段，不复制客户访问数据。参照系统内的付费额度不是本系统的功能限制。

每项验收需要同时证明：采集正确、持久化正确、授权正确、日期和筛选正确、页面可操作、导出正确。数据库支持 PostgreSQL 和 ClickHouse；没有实际运行验证的后端必须注明。新增字段不能伪造历史数据。

## 优先修复

用户确认：事件埋点几乎缺失、热力图和录制只统计 `/`、访问记录不显示 IP。

补充要求：可视化绑定参考 51.LA，必须有 iframe 与跳转模式；地图支持美国州、中国省级地区、欧洲国家/欧盟成员国；新控件复用现有 react-zen 输入框、单选、下拉框、开关和按钮。

后续补充：全局 SaaS Logo/左上角名称可配置；默认简体中文并修订全部可见译文；访客互动页复用概览样式且控制台无属性透传警告；地图保持原有大图尺度、筛选不丢失页面或明细滚动/缩放；流量过滤选项收拢；提供带过期/撤销/站点权限校验的 MCP 接口。

- 自动事件与埋点入口：已实现按钮、链接、下载、表单动作，保留命名事件，提供关闭和区域排除。采集回归测试验证不收集表单字段值、不阻止原站导航。可视化绑定正在进行真实浏览器全链路验收。
- 页面识别：已发现 `/?products/` 等查询路由被截为 `/`；录制单独开启时遗漏 SPA 导航。修复需验证 `/`、普通路径、查询路由、hash 路由、前进后退及录制分段。
- IP：已新增字段、规范化采集、访问列表和详情展示及搜索，已通过权限/数据库测试；历史缺失显示未知；分享页面不返回 IP。

### 可视化绑定验收

已在 51.LA `/codeless` 实际进入 iframe 预览并点选元素，确认名称、当前页面/页面组/所有页面范围、PC/移动视图、已绑定高亮与 Shift 点击交互。未向参照站点保存任何规则。

本系统需要验证 iframe 与跳转两条流程；页面拒绝 iframe 时明确提供跳转入口。规则必须持久化，可编辑、停用、删除，并在正常访问中上报命名事件。编辑器中的试点操作不得污染正常流量。跨窗口通信同时验证 origin、source 和 websiteId。
